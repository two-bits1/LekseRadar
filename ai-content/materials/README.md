# Учебные материалы для ИИ-репетитора

Сюда кладутся файлы, по которым ИИ отвечает и составляет квизы. Загрузка в базу: `python ../load/load.py`.

```
materials/
  Matematikk/                      ← папка = предмет
    Lineære funksjoner/            ← подпапка = тема (необязательно)
      Kapittel 3.pdf
      notater.docx
    formelark.md                   ← файл без темы
  Naturfag/
    Fotosyntese/
      sammendrag.txt
```

- Форматы: `.pdf`, `.docx`, `.txt`, `.md`, `.html`. Название материала = имя файла.
- Скан PDF без текстового слоя не прочитается (нужен OCR) — скрипт напишет «текст не извлёкся».
- Повторная загрузка того же файла ничего не дублирует. Изменённый файл загрузится как новый материал.
- Без `--owner-id` материалы общие (видны всем ученикам).
- Не клади сюда личные данные учеников: тексты попадают в промпт модели.
