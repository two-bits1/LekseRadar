# Промпты

Сюда кладутся промпты, которые грузятся в базу (`python ../load/load.py`).

- Один файл = один промпт: `tutor.md`, `quiz_generator.md`, `answer_checker.md` и т.д.
- Имя файла без расширения = ключ в базе: бэкенд берёт текст через `SELECT get_prompt('tutor')`.
- В базу попадает весь текст файла как есть, поэтому в файле только сам промпт, без пояснений.
- Переменные пиши как `{{subject}}`, `{{materials}}` — их подставляет бэкенд.
- Изменил файл и запустил загрузку снова — в базе появится новая версия, старая останется
  (откат: `SELECT activate_prompt('tutor', 1)`).

Ключи, которые ждёт бэкенд, и переменные для них — в [examples/README.md](examples/README.md).
В `examples/` лежат образцы с пояснениями; они в базу не грузятся.
