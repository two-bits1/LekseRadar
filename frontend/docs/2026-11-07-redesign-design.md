# Редизайн LekseRadar — «Северное сияние»

Дата: 7 ноября 2026 · Ветка: `Frontend-setup` · Дедлайн: сегодня, 7 ноября (хакатон Oslo Sprint, 6–8 ноября)

## Зачем

LekseRadar — радар домашки: собирает задания со всех школьных платформ, а ИИ-репетитор объясняет тему
по шагам и не делает работу за ученика. Сейчас сайт выглядит как аккуратный прототип. Нужен цельный вид,
который с первого взгляда даёт два ощущения сразу: **спокойствие** и **«вау, технологично»** — для учеников
и для жюри хакатона.

## Для кого

Ученики и студенты **16–25 лет**. Телефон и компьютер — **поровну**.

## Цели

1. Весь сайт в стиле «Северное сияние»: стеклянные панели, мягкое свечение, живой шар ИИ в центре шапки.
2. Новый шар AI-veileder (см. ниже) — главный «вау»-элемент.
3. Убрать дубль «Profil» в шапке.
4. Язык интерфейса — Norsk (bokmål), English, Русский — выбирается **только в настройках** и меняет весь сайт.

## Не цели

- Новые функции и новые запросы к API. Меняется вид, поведение сайта — нет (кроме языка).
- Изменения бэкенда.
- Голосовой ввод, переключатель языка в шапке.

## Анти-цели (провал, даже если «работает»)

- Яркие насыщенные цвета на больших площадях — ломает спокойствие (палитра из исследований, `COLORS.md`).
- Текст с контрастом ниже WCAG AA, чистые `#000` / `#FFF` для фона и текста.
- Анимации, которые нельзя выключить: при «уменьшить движение» в системе всё движение отключается.
- Сайт, который не работает на телефоне.

## Решения заказчика

| Тема | Решение |
|---|---|
| Направление | «Северное сияние» — тёмный, стекло, живой шар |
| Палитра | палитра из исследований остаётся основой; **шар и акценты можно ярче** |
| Шар | смесь трёх вариантов; клик → открывает чат; живёт **только в шапке, по центру** |
| Шар: клик | распадается на частицы тех же цветов, форма шара чуть увеличивается по радиусу |
| Шар: наведение | внутренности переливаются |
| Шапка, аккаунт | вариант B: **Profil остаётся в меню**; справа только «Logg inn» до входа, после входа справа пусто |
| Разделы у шара | Kalender (Lekser), Læringskort |
| Тема по умолчанию | авто, как сейчас (тёмная с 20:00 до 07:00 или по режиму устройства) |
| Шрифт | ровный системный — **Inter** |
| Плашка «En liten smakebit…» | оставить |
| Логотип | освежить, смысл тот же (радар) |
| Язык | nb / en / ru, **только в настройках**, для всего сайта |
| Объём | весь сайт |
| Анимации | 4 из 5 |

## Мои решения (можно поменять)

- **Шапка:** Kalender, Læringskort | шар | Profil, Innstillinger — по два пункта с каждой стороны, симметрично.
- **Шар «думает»:** пока ИИ отвечает в чате, шар в шапке крутится быстрее (это то же место, где он живёт).
- **Язык и ИИ:** выбор языка в настройках у вошедшего пользователя также сохраняется в профиль
  (`PATCH /users/me`, поле `locale`), чтобы ИИ-репетитор отвечал на том же языке.
  Поле «Språk» убирается из формы профиля, чтобы язык выбирался в одном месте. Профиль `nn` показывается как Norsk.
  После входа главный — язык из профиля (на новом устройстве сайт сразу на языке ученика); до входа — выбор,
  сохранённый на этом устройстве.
- **Что переводится:** весь текст интерфейса. Демо-задания и карточки (`data.ts`) остаются на норвежском —
  это материалы норвежской школы. Сообщения об ошибках от бэкенда показываются как пришли.
- **Перевод без библиотеки:** свои словари `nb` / `en` / `ru` и хук `useT()`; выбор хранится в `localStorage`,
  по умолчанию `nb`; `<html lang>` и формат дат следуют языку.
- **Шрифт** Inter подключается с Google Fonts (как сейчас DM Sans).

## Шар AI-veileder

Смысл: радар, который «видит» задание, а при клике раскладывает его на части — как репетитор раскладывает задачу на шаги.

| Слой | Что | Откуда |
|---|---|---|
| Оболочка | стеклянная сфера: блик сверху-слева, светлый ободок, внутренняя тень | вариант C «Жемчужина» |
| Внутри | 4 медленно вращающихся цветовых пятна (бирюза, синий, персик, лаванда) | вариант B, ярче |
| Луч радара | медленно вращающийся световой сектор | название «Radar» |

| Состояние | Поведение |
|---|---|
| Покой | лёгкое «дыхание» (масштаб ±3,5 % за 5 с), пятна вращаются медленно |
| Наведение / фокус | пятна вращаются ~в 2,5 раза быстрее, ярче и насыщеннее (как вариант A «Плазма»), луч заметнее |
| Клик / Enter | оболочка увеличивается на ~10 %, содержимое распадается на ~170 частиц тех цветов, от шара расходится кольцо, сразу открывается `/chat`; через ~1 с шар собирается обратно |
| ИИ думает | пока в чате ждём ответ, вращение быстрее, лёгкая пульсация |
| Уменьшить движение | никакой анимации, клик просто открывает чат |

Шар — кнопка с подписью «AI-veileder» и `aria-label`. В тёмной теме ядро тёмное и цвета светятся, в светлой —
ядро светлое, цвета мягче. Прототип: `lekseradar_header_orb_prototype` (показан в обсуждении 7 ноября).

## Стиль

- **Цвета:** токены из `COLORS.md` остаются. Добавляются: стекло (полупрозрачная поверхность + размытие фона),
  мягкое свечение сияния вверху страницы (бирюза + синий, низкая прозрачность, в светлой теме слабее),
  более яркие акценты для шара.
- **Стекло:** шапка и карточки — полупрозрачные панели с `backdrop-filter: blur`, тонкая светлая граница.
  Без поддержки `backdrop-filter` — обычная непрозрачная поверхность.
- **Шрифт:** Inter для всего текста (заменяет DM Sans и Manrope).
- **Движение (4/5):** плавное появление карточек, реакция на наведение, переходы между темами; всё отключается
  при `prefers-reduced-motion`.
- **Логотип:** иконка радара + «LekseRadar.», обновлённая под Inter и новый акцент.

## Страницы

Все страницы получают новый стиль. По порядку важности для показа:

1. Вход и регистрация
2. Главная (дашборд)
3. Чат (список и переписка)
4. Kalender, Læringskort / квиз
5. Профиль, настройки (тут же выбор языка), «Kommer snart», 404, /status

## Порядок работы

Каждый пункт — отдельный коммит в `Frontend-setup`; после каждого сайт собирается и работает.

1. Общий стиль: токены стекла и сияния, Inter — сразу меняет все страницы.
2. Шапка и новый шар (вместе с «думает» в чате).
3. Перевод: словари nb / en / ru, выбор в настройках, сохранение в профиль.
4. Страницы по списку выше.
5. Проверка: тесты, сборка, светлая/тёмная тема, телефон (375 px) и компьютер, «уменьшить движение».

## На усмотрение исполнителя

Точные значения прозрачности, размытия и длительностей; раскладка карточек на каждой странице в рамках стиля;
формулировки переводов (по смыслу норвежских текстов).
